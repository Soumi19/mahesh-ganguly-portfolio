# Antigravity Setup

1. Extract this ZIP.
2. In Antigravity choose **Open Folder** and select `mahesh-ganguly-antigravity-portfolio`.
3. Run in the terminal:
   `python3 -m http.server 8000`
4. Open `http://localhost:8000`

Main files:
- `index.html`
- `assets/css/styles.css`
- `assets/js/app.js`
- `assets/images/mahesh-ganguly-hero.png`

The stylesheet included here is the latest cleaned version with responsive layouts,
premium hero styling, animations, publication briefs styling, and the updated
desktop portrait positioning.
