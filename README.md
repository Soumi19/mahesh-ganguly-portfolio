# Dr. Mahesh Prasad Ganguly — Portfolio

Antigravity-ready static website project.

## Structure
- `index.html` — website markup and SEO metadata
- `assets/css/styles.css` — all website styles and responsive rules
- `assets/js/app.js` — navigation, reveal, and interaction JavaScript
- `assets/images/` — hero portrait and favicon

## Run locally in Antigravity
1. Open this entire folder in Antigravity.
2. Open the terminal.
3. Run:
   `python3 -m http.server 8000`
4. Visit:
   `http://localhost:8000`

You can also use Antigravity's Preview/Live Server feature if available.

## Deploy
This is a static website and can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or standard cPanel/shared hosting. Upload the contents of this folder with `index.html` at the web root.
